# Design references (made before the build window)

These mockups were drawn between 14 and 21 October 2026, before the build window opened, and are
declared as pre-existing material. They are references for the interface, not product code: the
app's interface is written during the hackathon in `app/web/`.

| File | Screen |
|---|---|
| `2_accueil.*` | Home: paste a plot or a claim, or run the demo case |
| `3_enquete_en_direct.*` | Live investigation: the trace as it happens, the Evaluator's rejection highlighted |
| `4_dossier_de_preuves.*` | Evidence file: verdict, findings with sources, the flip, "try to fool it" |
| `1_ecran_principal_enquete.*` | Main investigation screen, all panels |
| `systeme_visuel.*` | Visual system "Field instrument": Geist and Geist Mono, ink #0E1A14, forest #14402B |

Satellite backgrounds in the PNG captures: EOX Sentinel-2 cloudless (CC BY-NC-SA 4.0), contains modified
Copernicus Sentinel data. They are not used by the app.
